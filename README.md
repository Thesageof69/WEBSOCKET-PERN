# WEBSOCKET-PERN

A full-stack PERN application demonstrating real-time communication with WebSockets.

## Technologies
- React
- Node.js and Express.js
- PostgreSQL
- WebSockets
- JavaScript

## Highlights
- Full-stack frontend and backend integration.
- Real-time updates through WebSocket communication.
- Database-backed application workflows.
- Structured client and server code.

## Getting started
1. Clone the repository.
2. Install the dependencies for the client and server.
3. Configure the required environment variables.
4. Start the backend and frontend development servers.

## Security
Do not commit passwords, tokens, API keys or database credentials. Use local environment variables for sensitive configuration.
